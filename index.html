03. Projects

Things I've built.

001 · CNN ACCELERATOR

Efficient Inference Architecture on FPGA

CNN inference accelerator designed and synthesized in Verilog for real-time traffic sign recognition (GTSRB, 10 classes) on the PYNQ-Z2 FPGA, achieving 96% test accuracy at 69% DSP utilization. Integrated AXI DMA for high-throughput image transfer in place of GPIO-based pixel I/O, resolving AXI-Stream handshaking issues between the DMA IP and the custom CNN compute core. Profiled end-to-end inference latency and identified data movement as the primary bottleneck.

Verilog CNN AXI DMA PYNQ-Z2 Vivado
002 · CPU PROCESSOR
↗

RISC-V Pipelined Processor

5-stage pipelined RV32I processor designed in SystemVerilog with a complete datapath and control unit spanning fetch, decode, execute, memory, and write-back stages. Verified instruction-level correctness through self-checking testbenches and waveform-based simulation across the RV32I base instruction set.

SystemVerilog RISC-V RV32I Pipelining Hazard Handling Forwarding
003 · PROTOCOL
↗

UART Protocol on FPGA

Implementation of the UART serial communication protocol using Verilog HDL on an FPGA platform. Covers baud rate generation, transmitter and receiver logic, and functional simulation with testbenches.

Verilog UART FPGA Serial Communication Nexys A7
004 · EMULATOR

RISC-V Emulator in C

Modular RISC-V RV32I emulator built in C with separate fetch, decode, ALU, control unit, and memory modules mirroring real hardware datapath stages. Validated instruction execution against a hex-encoded test program.

C RISC-V RV32I Emulator Computer Architecture
