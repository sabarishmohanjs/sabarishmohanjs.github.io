03. Projects

Things I've built.

001 · CNN
↗

Fall Detection using CNN

CNN-based real-time fall detection system implemented entirely in Verilog HDL. Trained in Python with TensorFlow, weights exported as .mem files. Processes 32×32 grayscale images and classifies as "Fall" or "Not Fall" using fixed-point arithmetic.

VerilogCNNMachine LearningXilinx VivadoSimulation
002 · CPU Processor
↗

RISC-V Single-Cycle Processor

Verilog implementation of a RISC-V RV32I processor executing instructions in a single clock cycle. Integrates ALU, Control Unit, Register File, Data & Instruction Memory, and a testbench example includes computing the sum of the first 10 natural numbers.

VerilogRISC-V RV32IComputer ArchitectureRIPES
003 · Protocol
↗

UART Protocol on FPGA

Implementation of the UART serial communication protocol using Verilog HDL on an FPGA platform. Covers baud rate generation, transmitter and receiver logic, and functional simulation with testbenches.

VerilogUARTFPGASerial CommunicationNexys A7 FPGA Board
004 · Assembly
↗

RISC-V Ripes Simulator

RISC-V Assembly Language Programs (ALP) simulated using the Ripes visual pipeline simulator. Explores instruction-level execution, register states, and pipeline behaviour across various RISC-V programs.

RISC-V AssemblyRipesCOAISA
005 · Open-source

eSim Open Source Contribution

eSim is an open-source Electronic Design Automation (EDA) tool developed by the FOSSEE team at IIT Bombay. Contributed about 10 digital IC subcircuits to eSim as part of FOSSEE Summer Fellowship 2025.
